# 我的工作站

一个纯静态的个人工作站：外观是一只木盒，里面叠着七张便利贴。

| 便利贴 | 内容 |
| --- | --- |
| 搜索 | 谷歌 / 必应 / 百度，输入关键词回车在新标签页搜索 |
| 常用网站 | 自定义网站图标栏 |
| 自选行情 | 股票 + 基金，走势图支持分时 / 日 / 周 / 月 |
| 打卡日历 | 月历视图，点日期补记或取消，右侧是本月概览 |
| 环境与设备 | 网络状态与机型信息 |
| 视频下载 | 生成 yt-dlp 一键下载脚本 |
| 数据备份 | 导出 / 导入本机数据 |

盒盖上是北京时间、日期与主题切换。便利贴叠放在一起，**上滑**（或滚轮、鼠标拖动、
↑↓ 方向键、右下角圆点）可以切换。所有数据只存在本机浏览器的 `localStorage`。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

产物在 `dist/`，纯静态文件，可部署到任意静态托管。

## 部署

仓库内的工作流（`.github/workflows/deploy.yml`）会在每次推送时自动构建，
并把构建产物提交到 `docs/` 目录。GitHub Pages 设置为从 `main` 分支的
`/docs` 目录发布即可，推送到 `main` 后网站自动更新。
